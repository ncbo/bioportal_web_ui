Autocomplete jQuery compatibility tests

From the repository root, run python3 -m http.server 8000 --bind 127.0.0.1, then open http://127.0.0.1:8000/test/javascript/autocomplete_compatibility.html. Only the pinned jQuery/Migrate test libraries require internet access. Search responses are fixtures; Rails and the BioPortal API are not used.

Each case uses a fresh iframe. Reload to rerun.
