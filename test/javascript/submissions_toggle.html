Submissions toggle Stimulus tests

With npm dependencies installed, run python3 -m http.server 8000 --bind 127.0.0.1 from the repository root, then open http://127.0.0.1:8000/test/javascript/submissions_toggle.html. Reload to rerun; expect six passing cases. No CDN, jQuery, or Migrate is required.

These tests run the production controller with real Stimulus and the application's hidden-row CSS against fixture tables. They cover the five- and ten-row limits, state synchronization, independent tables, and connection lifecycles. Run bundle exec rails test test/views/submissions_toggle_view_test.rb for rendered-template coverage. Facebox and API requests are not exercised here.
