Checkbox state compatibility tests

Run python3 -m http.server 8000 --bind 127.0.0.1 from the repository root, then open http://127.0.0.1:8000/test/javascript/checkbox_state.html. Internet access is needed for the pinned jQuery 2.2.4 test library. Reload to rerun; expect six passing cases.

These tests execute the application's ontology picker, search-option restoration, and admin confirmation code against fixture DOM, with and without Migrate. Rails values are substituted; search requests, confirmation dialogs, and form submissions are stubbed. No account changes or API requests are made.
