Delegated application event tests

After yarn install, run python3 -m http.server 8000 --bind 127.0.0.1 from the repository root, then open http://127.0.0.1:8000/test/javascript/delegated_events.html. Only the pinned jQuery and Migrate comparison libraries need internet access. Rails and the BioPortal API are not used.

These tests execute the application handlers against fixture DOM, with and without Migrate. Network requests, DataTables rendering, and Facebox display are stubbed. The tree tests use real Stimulus connect/disconnect cycles. Reload to rerun.
