Public widget loading tests

Serve the repository root with python3 -m http.server 8000 --bind 127.0.0.1, then open http://127.0.0.1:8000/test/javascript/widget_loading.html. Pinned jQuery/Migrate host libraries need internet access. The actual widget entry points and dependencies are loaded; search responses are fixtures. Rails and the BioPortal API are not used. Reload to rerun.

Each case uses a fresh iframe and gives another library ownership of $. Tests cover independent and concurrent widgets, existing jQuery/Migrate/autocomplete, repeat initialization, replacement DOM, and retry after a failed dependency download. The widgets must never request Migrate.
